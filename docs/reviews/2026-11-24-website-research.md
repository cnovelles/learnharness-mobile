# Website research for OrbiTutor (issue 22, phase B2)

Date: 2026-11-24. Purpose: find the structure patterns of good app and open-source project pages before we design the OrbiTutor one-page site. We take patterns, not text, layouts or art.

## Method and limits

- We read the pages as text (WebFetch). For learnharness.ai we also read the HTML and the CSS.
- Ghostty, Anytype and Logseq render with JavaScript and gave almost no text. We skipped them.
- No page was copied. The wording, the layout and the art of the OrbiTutor page are our own.

## How forks credit their upstream

- **VSCodium:** names VS Code in the hero and explains the relation in a "Why" section. Thanks the contributors.
- **LibreWolf:** names Firefox in the tagline, calls itself an independent variant in About, and has a "not affiliated" line.
- **Mullvad Browser:** says in the intro that it is made with the Tor Project.
- **Element:** presents Matrix as its base on the whole page.
- **Forgejo:** does not name Gitea on its home page. This reads as an erasure. We do not do this.

## Decisions for the OrbiTutor page

1. **Section order:** slim nav, hero, "How it works" (four steps), "Mac and iPhone", "Download", "About", footer.
2. **Credit:** the user asked for the LearnHarness credit in the About section, not in the hero. The About section names LearnHarness and Amos Blomqvist, links to learnharness.ai and the upstream repository, says what OrbiTutor adds (the iPhone app), says thank you, and says that OrbiTutor is independent and not endorsed by the LearnHarness project (the LibreWolf pattern). The footer repeats the credit with the copyright.
3. **Downloads:** no public build exists. Each platform has a card with a "Coming soon" badge, a short reason, the source steps in a `<details>` element, and links to the real GitHub pages. No store badges, no invented URLs and no dead links.
4. **License:** the footer says AGPL-3.0-only, links the license text, and links the complete source of both apps. It keeps the LearnHarness copyright next to the OrbiTutor one.
5. **Style:** the Grove palette (one green accent on the issue 18 neutrals), light and dark from `prefers-color-scheme`, system fonts only (a serif for titles, the system sans for text), no scripts, no cookies, no external requests (a Content Security Policy blocks them).
6. **Open:** real screenshots help most (IINA, Obsidian and the upstream all use them). The mockup uses the logo with orbit rings instead. Screenshots must not show the user's real courses, so they need the golden test data and the new palette (after phase D). The user decides.
